Before you install

  • Back up your OpenEmu library first (~/Library/Application Support/OpenEmu). This build changes how artwork is stored, so going back to an older OpenEmu afterwards may not show your new artwork.
  • Installing replaces /Applications/OpenEmu.app with this build.
  • This is a test build. It does not update through Sparkle.

Install

  1. Double-click Install in this disk image. It copies the app to /Applications and the cores to ~/Library/Application Support/OpenEmu/Cores/.
  2. Open OpenEmu from /Applications.

What to try

  • Big Picture: Window menu, Big Picture (Spike), or Control-Command-B. Esc or the Home button leaves it.
  • Nintendo 3DS and PlayStation 2: bring your own game files (and your own PS2 BIOS). We do not provide any.
  • Artwork: right-click a game, then Choose Artwork… or Import Artwork from Folder…; Preferences has the new Artwork tab.
  • FBNeo: choose it as the Arcade core in Preferences, Cores.
